🚀 如何使用

  • 阅读：点击卡片进入课程，左侧为章节目录；右上角可切换明暗主题，Ctrl+K 全站搜索。
  • 动手：Python 代码块右上角有「运行」按钮，可直接在浏览器里执行（Pyodide）；也可用「复制」拿到本地跑。
  • 练习：每门课末尾习题带折叠式参考答案，点击展开。
  • 扩展：源文件在 docs/md/；修改后运行 python build.py 增量重建（--force 全量）。
  • 本地示例：code/<课程>/ 目录下为独立可运行脚本，Python 示例零依赖。
